The **Angular Material Component Development Kit (CDK)** is a set of behavior primitives for building UI components. It provides a foundation for developing high-quality, accessible Angular components without enforcing a specific visual design.

## What is the CDK?

The CDK is a collection of well-tested tools that help you build custom components with:

- **Accessibility**: Built-in support for screen readers, keyboard navigation, and focus management
- **Portability**: Create reusable components that work across different contexts
- **Flexibility**: No opinionated styles - bring your own design system
- **Performance**: Optimized for production applications

## Installation

```bash
npm install @angular/cdk
```

## Categories

The CDK is organized into three main categories:

### Common Behaviors

Utilities for implementing common interaction patterns:

- [Accessibility (a11y)](/cdk/a11y) - Focus management, live announcements, high contrast detection
- [Bidirectionality (bidi)](/cdk/bidi) - LTR/RTL layout support
- [Clipboard](/cdk/clipboard) - Copy text to clipboard
- [Drag and Drop](/cdk/drag-drop) - Sortable lists and free dragging
- [Layout](/cdk/layout) - Responsive breakpoint detection
- [Observers](/cdk/observers) - Observe DOM changes
- [Overlay](/cdk/overlay) - Floating panels and popovers
- [Platform](/cdk/platform) - Browser and device detection
- [Portal](/cdk/portal) - Dynamically render content
- [Scrolling](/cdk/scrolling) - Virtual scrolling and scroll detection
- [Text Field](/cdk/text-field) - Auto-resizing textareas

### Components

Unstyled component primitives:

- [Accordion](/cdk/accordion) - Expandable panels
- [Dialog](/cdk/dialog) - Modal dialogs
- [Listbox](/cdk/listbox) - Accessible listbox pattern
- [Menu](/cdk/menu) - Context menus and menu bars
- [Stepper](/cdk/stepper) - Step-by-step workflows
- [Table](/cdk/table) - Data tables with sorting and pagination
- [Tree](/cdk/tree) - Hierarchical tree structures

### Utilities

Helper functions and tools:

- [Coercion](/cdk/coercion) - Type conversion utilities
- [Collections](/cdk/collections) - Data source abstractions
- [Keycodes](/cdk/keycodes) - Keyboard key constants
- [Testing](/cdk/testing) - Component test harnesses

## Design Philosophy

The CDK is designed to be:

1. **Composable**: Mix and match behaviors to create custom components
2. **Tree-shakeable**: Only bundle what you use
3. **Framework-agnostic patterns**: While built for Angular, the concepts apply broadly
4. **Production-ready**: Used by Angular Material and thousands of applications

## Getting Started

Import individual modules as needed:

```typescript
import {DragDropModule} from '@angular/cdk/drag-drop';
import {OverlayModule} from '@angular/cdk/overlay';
import {A11yModule} from '@angular/cdk/a11y';

@NgModule({
  imports: [DragDropModule, OverlayModule, A11yModule],
})
export class AppModule {}
```

Or use standalone imports:

```typescript
import {CdkDrag, CdkDropList} from '@angular/cdk/drag-drop';

@Component({
  standalone: true,
  imports: [CdkDrag, CdkDropList],
})
export class MyComponent {}
```
